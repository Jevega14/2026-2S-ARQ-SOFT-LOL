# Evidencias de las sesiones con usuarios

Solo material real de las sesiones (nada de ejemplos ni datos simulados).

| Carpeta | Contenido | Nombre sugerido |
| :-- | :-- | :-- |
| `logs/` | Copia de `logs/audit.jsonl` al terminar cada sesión | `audit-20261128-sesion1.jsonl` |
| `capturas/` | Partida en curso, cierre válido, cierre rechazado, ganador | `U01-cierre-valido.png` |
| `videos/` | Grabaciones de pantalla cortas, o `enlaces.md` con links | `sesion1-U01-U02.mp4` |
| `encuestas/` | Exportación del formulario o fotos de las hojas | `encuesta-sesion1.csv` |

No subir rostros sin consentimiento ni nombres reales. Archivos de más de 50 MB: enlazarlos en `videos/enlaces.md`.
